# todmvi Documentation

todmvi converts images into dmview's image files (`.dmvi`): libtodmvi does
the conversion, todmvi is its command-line tool.

## Contents

- **[api-reference.md](api-reference.md)** - libtodmvi, and the todmvi command line

View documentation using `dmf-man`:

```bash
dmf-man libtodmvi          # Main documentation
dmf-man libtodmvi api      # API reference
```
